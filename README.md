# Node.js + Express API

## Features
- ES Modules (JavaScript)
- Express server
- Basic security: Helmet & CORS
- MVC structure: controllers, routes, models

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start server:
   ```bash
   npm start
   ```

## Project Structure
- app.js: Main entry point
- controllers/: Route handlers
- routes/: API routing
- models/: Data models
